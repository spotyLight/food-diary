# Дневник питания

Android-приложение для дневника еды и самочувствия с поиском возможных продуктов-триггеров. Работает без интернета, все записи хранятся на телефоне.

## Что умеет

- Записывать приёмы пищи (тип, время, продукты, заметка) и самочувствие (симптомы, сила 1–10, заметка).
- Сопоставлять записи: какие продукты чаще других предшествуют симптому в выбранном окне (3–48 часов), с оценкой силы связи и типичной задержкой.
- Выгружать данные в CSV (для Excel / Google Таблиц) и JSON (резервная копия), загружать JSON обратно.

## Как установить

1. Откройте на телефоне страницу **Releases** этого репозитория (справа на главной странице).
2. Скачайте файл `food-diary-…apk` из последней версии.
3. Откройте его и разрешите установку из этого источника, если Android спросит.

Каждое изменение в ветке `main` автоматически собирает новую версию (GitHub Actions → «Build APK»). Новая версия ставится поверх старой, записи сохраняются.

## Устройство

- `app/src/main/assets/index.html` — весь интерфейс и логика анализа (HTML + JS), данные хранятся в `localStorage` приложения.
- `app/src/main/java/.../MainActivity.java` — оболочка WebView, сохранение файлов через системный диалог, выбор файла для импорта, кнопка «Назад».
- `app/fooddiary.keystore` — ключ подписи. Он нужен, чтобы обновления ставились поверх старой версии. Не меняйте его, иначе для обновления придётся удалить приложение вместе с данными.
